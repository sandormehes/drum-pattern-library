= Notation

Patterns use four sixteenth-note steps per beat. A one-bar 4/4 pattern therefore has 16 steps; longer patterns continue on the same source line in groups of four. Numbered steps remove the need to understand spoken sixteenth-note counting. Vertical separators divide beats, while each instrument remains on one source line for readable Git diffs.

== Step symbols

[cols="1,2,5", options="header"]
|===
|Symbol |Meaning |Use

|`-`
|Rest
|No hit on this step.

|`x`
|Normal hit
|The default articulation.

|`X`
|Accent
|A deliberately stronger hit.

|`g`
|Ghost hit
|A quiet supporting hit.

|`o`
|Open or sustained hit
|Commonly used for an open hi-hat or ringing percussion.
|===

== Grid

[drum-pattern]
----
KICK   | X--- ---x --X- ----
SNARE  | ---- X--- ---- X---
HI-HAT | x-x- x-x- x-x- x-x-
----

The symbols after the track label are the canonical pattern data. Use readable uppercase track labels, exactly four characters per beat, and one space between beats. Every track must contain the number of steps declared by the page's `bars` metadata. The custom `drum-pattern` block converts this compact source into the visual grid and legend automatically.

== Timing and dynamics

The grid describes the rhythmic skeleton, not every performance detail. Record swing, microtiming, velocity, and articulation in a pattern's metadata or performance notes. This keeps the step data simple while preserving the character of the groove.

== Playback

Each published grid has a *Play pattern* control. It uses neutral synthesized drum sounds in the browser, so it is useful for hearing placement rather than reproducing a record or prescribing samples. Set tempo and sixteenth-note swing with the sliders; playback loops until *Stop playback* is selected.

For meters or subdivisions that do not fit a 16-step grid, state the meter and subdivision explicitly and retain the same rule: one character per step, grouped by beat.
