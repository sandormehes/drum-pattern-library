= Methodology

The library distinguishes what is heard or transcribed from what is inferred. Every pattern should be understandable, playable, and traceable without requiring access to a particular DAW.

== Adding a pattern

. Assign a stable ID. Use a short family prefix, an approximate era or tempo marker when useful, and a sequence number.
. State meter, subdivision, length, and a useful tempo range.
. Put each instrument or rhythmic role on its own fixed-width line.
. Describe the groove's character and include only performance notes that affect the feel.
. Record provenance, source details, and confidence.
. Link closely related patterns rather than duplicating their background text.

== Provenance

Original:: Created for this library and not presented as a transcription.
Transcription:: Derived by listening to a named recording or performance.
Adaptation:: Intentionally changes a documented source pattern.
Traditional:: Widely circulated, with no single reliable point of origin claimed.

Use a confidence value of _high_, _medium_, or _low_ for transcriptions and historical claims. If the source is uncertain, say so directly.

== Review checklist

* The number of steps matches the declared meter, subdivision, and bar count.
* Only symbols defined in xref:notation.adoc[Notation] appear in the grid.
* Metadata describes the pattern without tying it to a specific sample.
* Musical edits appear as small, legible line changes in a Git diff.
* Factual claims have a source or are clearly labeled as interpretation.
