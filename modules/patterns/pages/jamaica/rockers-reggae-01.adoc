== Character

A rockers-oriented study that adds a more active kick path and backbeat to the reggae pulse. It is one possible working pattern, not a claim that “rockers” has a single canonical grid.

== Performance notes

* Keep the beat-three kick strongest; the late kick is a pickup.
* Let the ghost percussion disappear into the drum ambience.
* In a dub treatment, remove events rather than filling every gap.
