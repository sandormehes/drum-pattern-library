== Pattern

[drum-pattern]
----
KICK   | X--- -x-- ---x --x- | --x- ---- x--- -x--
SNARE  | ---- X--- ---- X--- | ---- X--- ---- X---
CLAP   | ---- ---- --g- ---- | ---- ---- X--- ----
HAT    | x-xx --x- x-x- -xxx | -x-x xx-- x-xx --x-
PERC   | --x- x--- -x-- ---- | x--- --x- ---x x--g
----

== Character

The snare stays fixed while the kick relay moves in the opposite direction across
the bar line: a compact first-bar cluster opens into a more spacious second bar.
That counterphase keeps the fast grid active without relying on a continuous bass
drum pattern.

== Design device

Counterphase:: The kick's busiest point arrives before the bar-two snare landmark, then retreats afterward.
Landmarks:: A stable half-time snare makes the rearranged low-drum responses easy to follow.
Surface:: Hats switch between short bursts and rests; percussion handles the leftover sixteenth-note gaps.

== Performance notes

* Keep kick decay extremely short so adjacent attacks read as separate gestures.
* Program the clap as a low-velocity colour rather than a second main snare.
* Test the loop at 160 BPM before adding bass; a long bass tail can obscure the counterphase.
