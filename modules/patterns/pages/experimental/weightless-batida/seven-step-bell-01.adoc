== Pattern

[drum-pattern]
----
KICK   | X--- ---- ---x ---- | ---- x--- ---- --x-
SNARE  | ---- ---- X--- ---- | ---- ---- X--- ----
BELL   | x--- ---x ---- --x- | ---- -x-- ---- x---
PERC   | --x- x--- -x-x ---- | x--x --x- x--- -x--
SHAKER | -g-g -g-g -g-g -g-g | -g-g -g-g -g-g -g-g
----

== Character

The bell repeats every seven sixteenths, so it crosses beats and the bar line before approaching its starting phase. A steadier half-step foundation makes the rotation audible without resolving it inside the two-bar excerpt.

== Design device

Rotation:: Bell events occur on absolute steps 1, 8, 15, 22, and 29.
Continuity:: Ghost shakers preserve the full-tempo grid underneath the sparse foundation.
Interlock:: Main percussion avoids the bell attacks.

== Performance notes

* Use one unmistakable bell timbre for every rotating event.
* Keep the shaker almost subliminal; it is timing glue, not a lead layer.
* Extend the pattern to seven bars if a full phase return is required.
