== Pattern

METAL  | ---- ---o ---- ---- | ---- -x-- ---- o---
----

== Character

A busy percussion surface hangs inside a nearly empty kick-and-snare frame. Sustained metal hits imply a larger acoustic space without filling it with conventional cymbal timekeeping.

== Design device

Vacuum:: Foundation hits are too sparse to explain the groove by themselves.
Propulsion:: Dry percussion provides continuous forward motion.
Scale:: Two sustained metal events make the empty regions feel larger.

== Performance notes

* Keep kick and snare physically heavy but extremely short.
* Make percussion pitches contrast without forming an obvious melody.
* Allow metal tails to overlap events, but not each other.
