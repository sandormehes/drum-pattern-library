== Pattern

KICK   | X--- ---- --x- ---x | x--- -x-- ---- ---X

HI-HAT | x-x- x-xx x-x- x-xx | xx-x -x-x xx-x -x-x

== Character

Bar two reverses each lane's first-bar step order. The result is a literal grid mirror: recognizable material returns with reversed momentum and an accented final kick.

== Transformations

Parent:: {parent-pattern}
Reduction:: Begin from the parent pattern's breakbeat roles rather than its exact events.
Mirror:: Reverse all 16 step positions to generate bar two.
Accent:: Strengthen the final mirrored kick so the loop boundary remains audible.

== Performance notes

* Use consistent sounds across both bars so the reversal is perceptible.
* Shorten cymbal tails before the mirrored bar if they blur the boundary.
* For a less literal variation, mirror only kick and snare while leaving hats unchanged.
