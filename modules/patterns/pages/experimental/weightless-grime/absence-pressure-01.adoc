== Pattern

[drum-pattern]
----
KICK   | X--- ---- ---- ---x | ---- ---- -x-- ----
SNARE  | ---- X--- ---- ---- | ---- ---- ---- X---
HAT    | ---- --x- ---- ---- | -x-- ---- ---- --x-
METAL  | ---- ---- ---o ---- | ---- --o- ---- ----
PERC   | --g- ---- ---- x--- | ---- ---- x--g ----
----

== Character

The loop gives each major attack a wide, exposed field. A single kick begins the
first bar, but the expected second snare is withheld until the end of bar two;
metallic tails and near-silent ghost notes make the gap feel intentional rather
than unfinished.

== Design device

Withholding:: The usual half-time return is delayed by one and a half bars.
Tail:: Metal events occupy duration rather than rhythmic density, allowing their decay to become part of the phrase.
Pressure:: The few low-drum attacks are isolated enough to invite a bass response without requiring one.

== Performance notes

* Let the metal sound ring into empty cells, but filter its low end so it does not mask the kick.
* Keep ghost percussion barely above the noise floor; it should be felt before it is identified.
* A sustained sub note can enter after the first kick, then cut before the bar-two snare arrives.
