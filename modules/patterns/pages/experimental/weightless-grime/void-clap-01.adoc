== Character

This two-bar study begins without a downbeat kick and uses a clap as the only
clear bar-two marker. The low-drum attacks enter late, so the grid is sensed from
the distance between events rather than from any continuous pulse.

== Rhythmic roles

Void:: Bar one leaves the first half almost untouched, turning the late snare into an arrival.
Reframe:: The bar-two clap shifts the listener's expectation without asserting a conventional backbeat.
Trace:: Hats and percussion are isolated traces of subdivision, not a running timekeeper.

== Performance notes

* Keep the clap short and slightly brighter than the snare so it reads as a separate landmark.
* Resist filling the first sixteenth of either bar; the missing downbeats are structural.
* Automate a reverb tail to bloom after the bar-one snare, then remove it before the first bar-two kick.
