== Pattern

[drum-pattern]
----
KICK   | X--- ---- ---x ---- | ---- ---- ---- x---
SNARE  | ---- X--- ---- ---- | ---- ---- X--- ----
HAT    | -x-- ---- --x- ---- | ---- -x-- ---- ----
METAL  | ---- ---o ---- ---- | --o- ---- ---- ----
PERC   | ---- x--g ---- ---- | ---- ---- ---g x---
----

== Character

The first bar offers a conventional-looking kick and snare outline, then the
second bar removes nearly all foundation. The remaining snare, metal decay, and
final percussion event make the groove feel as if it is receding into a darker
space rather than resolving cleanly.

== Design device

Dropout:: Bar two strips away the expected restart kick and most subdivision cues.
Recession:: A metal attack moves earlier in bar two while the main snare moves later, stretching the perceived distance between impacts.
Return:: The final percussion event is deliberately too light to function as a fill; it suggests, rather than delivers, the restart.

== Performance notes

* Use a kick with a strong initial transient and a very short tail.
* Let the metallic layer have a longer decay than the snare, but duck it lightly at the snare attack.
* For a more severe version, mute every hat on alternate repeats and preserve only the metal tails.
