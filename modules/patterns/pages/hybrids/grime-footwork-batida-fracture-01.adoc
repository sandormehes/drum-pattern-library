== Pattern

[drum-pattern]
----
KICK   | X--x -x-- --x- x--- | --x- x--- -x-- --x-
SNARE  | ---- X--- ---- X--- | ---- --x- X--- ----
CLAP   | ---- ---- ---- ---- | ---- X--- ---- --g-
HAT    | x-xx -x-x xx-x -x-- | xx-x x--x -x-x xxx-
PERC   | -x-- --x- x--g --x- | x--- -x-g --x- x---
----

== Character

The fixed first-bar grime backbeat is broken open in bar two by a displaced snare and
an uneven kick relay. Fast hats and dry percussion keep the surface agile, while the
low drums leave enough negative space for a heavy bass answer.

== Rhythmic roles

Anchor:: Bar one makes the half-time grime reference audible before the pattern destabilizes it.
Fracture:: Bar two moves the main snare a sixteenth late and removes the expected first kick.
Velocity:: Hats use rapid, changing groupings rather than a repeating straight pulse.
Interlock:: Percussion occupies gaps around the kicks, with ghost notes softening the joins.

== Groove setting

Tempo:: Start near 152 BPM; slow it slightly only if the kick relay loses definition.
Timing:: Keep kicks and main snares dry and near-quantized. Push selected percussion a little late.
Dynamics:: Make the bar-two clap a secondary flash, not a new backbeat.

== Performance notes

* Use a short kick with a distinct transient so the dense placements remain readable.
* Change one percussion timbre each repeat; leave the event positions intact for several cycles.
* Let bass sustain across one or two absent kick positions instead of doubling the full grid.
