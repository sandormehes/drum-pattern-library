== Pattern

[drum-pattern]
----
KICK    | X--- ---- X--- --x-
CLAP    | ---- X--- ---- X---
HI-HAT  | x-x- x-x- x-x- x-x-
OPEN HH | ---- --o- ---- --o-
TOM     | ---x ---- -x-- x---
----

== Character

A crisp electroid pattern designed around 909-style articulations. Its regular hats and backbeat feel mechanical, while the late kick and low-tom cell keep the loop from settling into a straight house pattern.

== Rhythmic roles

Foundation:: Kick and clap define a firm machine grid.
Lift:: Open hats brighten the offbeats.
Disruption:: The tom lane crosses the kick pattern and creates the loop's funk.

== Performance notes

* Start with little or no swing; introduce timing variation only after the accents work.
* Tune the tom to interact with the bass rather than treating it as decoration.
* Shorten the second open hat if it masks the final kick.
