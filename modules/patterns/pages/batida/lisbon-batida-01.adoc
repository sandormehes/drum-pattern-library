== Pattern

[drum-pattern]
----
KICK   | X--- ---- --x- ---- | ---- -x-- ---- X---
SNARE  | ---- X--- ---- ---- | X--- ---- --g- ----
PERC A | -x-- --x- x--- -x-- | --x- x--- -x-- --x-
PERC B | ---x x--- --x- ---x | x--- ---x x--- -x--
METAL  | ---- ---- o--- ---- | ---- ---x ---- ----
----

== Character

An original percussion-first study in which the low drum changes position between bars while the two percussion lanes sustain motion. The metal lane supplies occasional scale without becoming a timekeeping part.

== Rhythmic roles

Foundation:: Kicks are infrequent enough that the loop is not defined by a conventional low-drum pulse.
Interlock:: Percussion lanes alternate density so one can retreat as the other becomes active.
Colour:: Metal arrives as an event with a tail, not a cymbal pattern.

== Performance notes

* Keep the percussion tones distinct in pitch or material: wood, skin, and metal work well.
* Do not quantize all lanes to identical velocity; make the reply notes softer.
* On every fourth pass, omit the final kick and let PERC B carry the return.
