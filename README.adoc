= Drum Pattern Library

A human-readable, Git-friendly drum-pattern library built with AsciiDoc and Antora. Version 0.2 adds a self-contained site theme, a guided entry point, and browse paths by feel, tempo, origin, and pattern type.

== Preview locally

You need Node.js 20 or newer. Antora reads local content through Git, so run these commands from a Git clone (or after initializing and making the first commit in a downloaded archive).

[source,shell]
----
npm install
npm run check
----

Open `build/site/index.html` in a browser.

The check command validates pattern metadata, source references, step counts, and symbols before building the site. The UI bundle lives in this repository, so building the site does not depend on downloading a remote theme.

== Add a pattern

. Copy one of the pages in `modules/patterns/pages/`.
. Give it a stable ID and filename.
. Keep every track on its own line so changes remain clear in Git diffs.
. Add the new page to `modules/patterns/nav.adoc`.

The complete notation and authoring rules are in the generated site under _Notation_ and _Methodology_.

== Publish on GitHub Pages

Push the repository to GitHub and, under *Settings > Pages*, choose *GitHub Actions* as the source. Every push to `main` then builds and publishes the site. Pull requests run the same build without publishing.
